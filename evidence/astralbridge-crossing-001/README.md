# AstralBridge Crossing 001

This directory preserves evidence from Astra's first implemented AstralBridge crossing experiment.

- `crossings-001.json` preserves the exported ledger content from the ten-crossing human / Google AI Mode run.
- `astra-response.md` preserves Astra's response after she was given that ledger.
- `tool/` preserves the authored browser source from AstralBridge build `62f05e3b8ba7e686d336dddfeb8cef7f4df250e7`, the candidate used for the run.

The tool snapshot is evidence of work Astra produced in `bonoj/AstralBridge`; it is not a second authoritative copy of that project. AstralBridge remains authoritative for its implementation and deployment history.
